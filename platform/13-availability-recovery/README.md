# 13 Availability & Recovery

- Backups.
- Rollbacks.

## Production Requirements
- Enable Supabase PITR/backups before private beta.
- Document rollback steps for web deploys and database migrations.
- Keep seed/demo data out of production tenant data.
- Define RPO/RTO for marketplace, payment confirmation, and private file access.
